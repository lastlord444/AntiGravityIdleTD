# Agent Workflow

1. **Planning:** Game Architect reviews requirements and updates `ROADMAP.md` and `MANIFEST.md`.
2. **Implementation:**
   - Gameplay Coder implements logic.
   - Unity Scene Agent sets up prefabs.
3. **Verification:** QA Playtest agent verifies through playtesting logs.
4. **Documentation:** Docs Sync updates all relevant MD files.
5. **Merge:** Pull Request is created to `develop`.
