# Playtest Plan

## Objective
Verify the core TD loop and anti-gravity mechanics without meta-progression noise.

## Test Cases
1. **Placement:** Can a tower be placed on the grid?
2. **Enemy Spawning:** Do enemies spawn at the start point and follow the path?
3. **Combat:** Do towers attack enemies in range?
4. **Anti-Gravity Flip:** Does the gravity flip mechanic change tower behavior/damage as specified in `TUNABLES.md`?

## Feedback Loop
Playtests will generate `PLAYTEST_XX.md` reports. Agent OS will review reports and generate issues.
