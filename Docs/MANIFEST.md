# AntiGravityIdleTD - Proje Manifestosu

## Vizyon
Anti-gravity mekanikleriyle zenginleştirilmiş idle tower defense oyunu.

## Temel Özellikler
- **Idle Mekanik:** Oyuncu offline olsa bile ilerleme kaydedilir
- **Tower Defense:** Stratejik kule yerleştirme ve yükseltme
- **Anti-Gravity:** Yerçekimine meydan okuyan benzersiz oyun dinamikleri

## Teknik Stack
- **Unity:** 6.3 LTS
- **Render Pipeline:** Universal Render Pipeline (URP) 2D
- **Platform Hedefi:** Mobile (Android/iOS)
- **Mimari:** Service Locator + Event Channel pattern
