# Reference Repos

Bu projede hiçbir referans repo doğrudan base olarak kullanılmayacak. Her repo yalnızca pattern, fikir, mimari veya lisans kontrollü küçük örnek olarak incelenir.

## 1. Brackeys/Tower-Defense-Tutorial
- Kullanım: TD core loop, waypoint, turret targeting, wave mantığı.
- Lisans: Unlicense.
- Durum: Eski Unity tutorial.
- Karar: Kod komple alınmaz. Pattern incelenir.

## 2. prabdhal/Tower-Defence-3D
- Kullanım: level progression, tower upgrade, enemy variety, mobil build mantığı.
- Lisans: MIT.
- Karar: Seçmeli pattern incelenir; 3D/NavMesh sistemi alınmaz.

## 3. DrFlower/TowerDefense-GameFramework-Demo
- Kullanım: ileri seviye data-driven TD mimarisi, config yaklaşımı, object pool fikri.
- Risk: GameFramework ağırdır.
- Karar: Sadece mimari referans. Framework projeye sokulmaz.

## 4. thiago-souzaf/Tower-Defense-Game
- Kullanım: modern Unity 2022.3 proje akışı, low-poly stil, sade TD yapı.
- Karar: Sadece inceleme / küçük pattern.

## 5. davda54/tower-defense-unity
- Kullanım: Kenney asset kullanımı, Android/Web build pratikleri.
- Risk: Lisans kontrol edilmeden kod alınmaz.
- Karar: Sadece referans.

## Yasaklı kullanım
- GPL kod projeye alınmaz.
- LICENSE dosyası olmayan repodan kod alınmaz.
- Asset lisansı belirsiz hiçbir şey import edilmez.
- Referans repo doğrudan fork/base yapılmaz.
