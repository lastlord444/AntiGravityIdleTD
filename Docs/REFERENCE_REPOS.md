# Reference Repos

We will study the following repos for architecture inspiration (GPL repos for review only, no direct code reuse):

- `Brackeys/Tower-Defense-Tutorial`: Good for simple TD flow. Unlicense.
- `DrFlower/TowerDefense-GameFramework-Demo`: Good reference, but GameFramework architecture is too heavy.
- `prabdhal/Tower-Defence-3D`: MIT license, good reference for mobile/upgrade/level systems.
- `thiago-souzaf/Tower-Defense-Game`: Modern Unity 2022.3, small repo.
