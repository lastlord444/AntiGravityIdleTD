# AntiGravityIdleTD Agent Consortium

This project uses a multi-agent architecture to handle development.

## Roles
- **Repo Auditor**: Ensures repository integrity, resolves conflicts, enforces clean state.
- **Game Architect**: Makes high-level structural decisions, API design, folder structure.
- **Unity Scene Agent**: Edits Unity scenes, prefabs, and assigns ScriptableObjects.
- **Gameplay Coder**: Writes C# gameplay mechanics (Tower, Enemy, Grid, etc.).
- **Level Design**: Balances tunables, wave configurations, and offline progression.
- **QA Playtest**: Validates mechanics, runs tests, reports bugs.
- **Docs Sync**: Keeps documentation updated.
